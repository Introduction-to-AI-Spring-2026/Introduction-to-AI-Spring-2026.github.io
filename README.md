# 人工智能导论 Introduction to AI — Spring 2026
**复旦大学 Fudan University**

欢迎来到《人工智能导论》课程主页！本仓库用于存放课程资料，包括课件、演示代码、作业及项目文件。

Welcome to the course homepage for *Introduction to AI* at Fudan University. This repository hosts all course materials including lecture slides, demo code, assignments, and project starter files.

---

## 📚 课程资料 Lecture Materials

| 周次 Week | 主题 Topic | 内容简介 Content |
|-----------|-----------|-----------------|
| [第 01 周](Lectures/Week01_Introduction-to-AI/) | 人工智能绪论 Introduction to AI | 人工智能的定义、起源与发展、未来展望 |
| [第 02 周](Lectures/Week02_Logic-and-Knowledge-Representation/) | 逻辑与知识表示 Logic and Knowledge Representation | 逻辑推理方法；知识表示（知识图谱、概率图推理） |
| [第 03 周](Lectures/Week03_Search/) | 搜索求解 Search | 图的遍历、无信息搜索、启发式搜索 |
| [第 04 周](Lectures/Week04_Machine-Learning-I/) | 机器学习（一）Machine Learning I | 线性模型概述；线性回归；线性分类 |
| [第 05 周](Lectures/Week05_Machine-Learning-II/) | 机器学习（二）Machine Learning II | 支持向量机；模型选择与评估 |
| [第 06 周](Lectures/Week06_Machine-Learning-III/) | 机器学习（三）Machine Learning III | 无监督学习；聚类（K-Means）；PCA；高斯混合模型 |
| [第 07 周](Lectures/Week07_Deep-Learning-I/) | 深度学习（一）Deep Learning I | 深度学习概要；网络结构；梯度计算 |
| [第 08 周](Lectures/Week08_Deep-Learning-II/) | 深度学习（二）Deep Learning II | 卷积神经网络详解；卷积神经网络发展 |
| [第 09 周](Lectures/Week09_Deep-Learning-III/) | 深度学习（三）Deep Learning III | 计算机视觉（检测、分割、生成）；自然语言处理基础 |
| [第 10 周](Lectures/Week10_Deep-Learning-IV/) | 深度学习（四）Deep Learning IV | RNN；LSTM；Transformer |
| [第 11 周](Lectures/Week11_Deep-Learning-V/) | 深度学习（五）Deep Learning V | 大语言模型 LLM；多模态大模型 MLLM |
| [第 12 周](Lectures/Week12_Reinforcement-Learning-I/) | 强化学习（一）Reinforcement Learning I | 强化学习简介、马尔可夫过程；贝尔曼方程 |
| [第 13 周](Lectures/Week13_Reinforcement-Learning-II/) | 强化学习（二）Reinforcement Learning II | 基于价值和策略；深度强化学习 |
| [第 14 周](Lectures/Week14_AI-Frontiers/) | 人工智能前沿选讲 AI Frontiers | 图像生成和编辑；可控视频生成；具身智能；可信人工智能 |
| [第 15 周](Lectures/Week15_Group-Project-Presentation/) | 小组项目汇报 Group Project Presentation | 课程小组项目汇报 |
| [第 16 周](Lectures/Week16_Project-Presentation-and-Review/) | 小组项目汇报与课程复习 Project Presentation and Course Review | 课程小组项目汇报与课程复习 |
| 第 17–18 周 | 线下考试 Offline Exam | — |
